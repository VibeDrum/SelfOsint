# 🔍 Self OSINT: Conscientização e Blindagem Digital

> "A privacidade não é sobre ter algo a esconder, é sobre ter algo a proteger!"

Este projeto foi desenvolvido com o objetivo de democratizar o conhecimento sobre **Self OSINT (Open Source Intelligence)**. Ele foi pensado para pessoas comuns que desejam entender quais rastros deixam na internet e como se proteger de possíveis ameaças digitais, como ataques de engenharia social.

Sabia que cerca de **90% das informações necessárias para um ataque cibernético estão disponíveis publicamente**? Nós somos, muitas vezes, nossos maiores informantes. Este guia prático vai te ajudar a investigar a si mesmo antes que um criminoso o faça.

---

## 🧭 O que você vai aprender?

* **Conceito de Self OSINT:** O ato de investigar a si mesmo para entender a sua exposição na web.
* **Anatomia do Rastro (Sombra Digital):** * *Pegada Ativa:* O que você posta conscientemente (redes sociais, check-ins, currículos).
    * *Pegada Passiva:* O que coletam de você sem você perceber (metadados de fotos, cookies, vazamentos de dados).
* **Demonstrações Práticas:** Como utilizar ferramentas gratuitas e técnicas de busca avançada para auditar sua segurança.
